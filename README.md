Piano Tuner · Klavírní ladička

A free piano tuner that runs in your browser — on a phone, tablet or computer. No install, no account, no ads.

Live version: https://tomkubak.github.io/WEB-Piano-Tuner-free

Features
Starts listening right away — just open the page and play a note.
Accurate in the low bass and the high treble: the pitch is computed from several partials, with the string's inharmonicity taken into account.
Partial strobe: one spinning disc per partial; it stands still when the partial is in tune and turns visibly even at a fraction of a cent.
Stretch tuning calculated from the inharmonicity measured on your piano, with four tuning styles (pure octaves, pure 12ths, double octaves, pure 19ths) and extra stretch for the treble and bass.
Note modes: Auto, Stepwise (follows you chromatically, never jumps an octave) and Locked.
Charts: sound spectrum, tuning curve with dots showing how each note is tuned, and inharmonicity across the keyboard.
Temperaments: equal, Pythagorean, just, ¼-comma meantone, Werckmeister III, Kirnberger III, Kellner, Vallotti, Young II — with any tonic.
Reference pitch adjustable from 415 to 466 Hz, plus a reference tone generator.
14 languages: Čeština, Slovenčina, Polski, Deutsch, English, Français, Español, Italiano, Português, Nederlands, Українська, Русский, 日本語, 中文.
Works offline and can be installed to the home screen or the Dock like an app.
Privacy

Microphone audio is processed only on your device. Nothing is recorded, uploaded or tracked. Settings are stored in your browser.

Install as an app
iPhone / iPad (Safari): Share › Add to Home Screen
Mac (Safari): File › Add to Dock
Chrome / Edge: the install icon in the address bar, or menu › Install

Allow microphone access when asked.

Hosting

The app is a plain static site (index.html, sw.js, manifests and icons) with no build step. It needs HTTPS for microphone access — GitHub Pages and Netlify both provide it.
